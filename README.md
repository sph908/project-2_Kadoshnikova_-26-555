# Primitive DB
Примитивная база данных с консольным интерфейсом.
Данные хранятся в JSON-файлах, работа идёт через текстовые команды.
## Возможности

- создание и удаление таблиц с описанием столбцов и их типов
- добавление, выборка, изменение и удаление записей
- проверка типов данных при вставке
- вывод результатов выборки в виде таблицы
- подтверждение опасных операций
- кэширование повторяющихся запросов
- замер времени выполнения операций

## Требования

- Python 3.12 или новее
- [uv](https://docs.astral.sh/uv/)

## Установка и запуск

```bash
uv sync
```

```bash
uv run project
```

Вместо `project` можно использовать `database` — это та же программа.

Чтобы установить пакет как самостоятельный инструмент и вызывать
его из любой папки:

```bash
uv build
uv tool install --force dist/*.whl
```

## Команды


`create_table <таблица> <колонка>:<тип> ...` создать таблицу 

`drop_table <таблица>` удалить таблицу

`insert into <таблица> values <значение> ...` добавить запись

`select from <таблица> [where <условие>]` выбрать записи

`update <таблица> set <условие> where <условие>` изменить записи

`delete from <таблица> where <условие>` удалить записи

`help` справка по командам

`exit` выйти из программы

## Правила ввода

- Типы столбцов: `int`, `str`, `bool`
- Столбец `ID` добавляется автоматически и нумеруется сам —
  в `values` его передавать не нужно
- Имена таблиц и столбцов не могут начинаться с цифры:
  подходит `column1` или `column_1`, но не `1column`
- Строковые значения записываются в кавычках: `name = "Анна Петрова"`.
  Без кавычек значение из цифр будет считано как число
- Несколько условий соединяются словом `and`:
  `where age = 20 and name = "Ann"`

## Хранение данных

`db_meta.json` структура всех таблиц: имена столбцов и их типы
`data/<таблица>.json` записи одной таблицы
Оба файла создаются автоматически при первой операции.
